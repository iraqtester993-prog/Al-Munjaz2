# اختبار قدرة المنجز السريع

`read-only-baseline.mjs` يقيس روابط عامة فقط ولا ينشئ حسابات أو طلبات ولا
يرسل رسائل. حدّه مقصود: 10 مستخدمين متزامنين و60 ثانية كحد أقصى، حتى يبقى
آمنًا عند تشغيله على الإنتاج.

لإجراء اختبار السعة الكامل، يجب أولًا إنشاء بيئة تجريبية منفصلة وبيانات
اختبار. هناك فقط نختبر تسجيل الدخول، إنشاء الطلب، قبوله، تحديث الحالة،
والدردشة، ثم نرفع الحمل تدريجيًا. لا تشغّل اختبار الكتابة على روابط المستخدمين
الحقيقية.

معيار القبول المبدئي:

- نسبة الأخطاء أقل من 1%.
- زمن الاستجابة P95 أقل من 2,000ms.
- لا تظهر أخطاء 500 أو 429 أو زيادة مستمرة في استهلاك الموارد داخل cPanel.

المحادثة تفحص الرسائل كل ثانيتين أثناء فتحها؛ لذلك يمثل سيناريو الدردشة أكبر
حمل تشغيلي ويجب قياسه منفصلًا في البيئة التجريبية.
