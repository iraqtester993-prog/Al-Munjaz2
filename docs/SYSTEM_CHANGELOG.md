# سجل تغييرات نظام المنجز

هذا هو المرجع الدائم لكل تغيير وظيفي أو تقني أو نشر إلى الاستضافة.

## قاعدة التوثيق

قبل اعتبار أي عمل مكتملاً، يُضاف إدخال هنا يتضمن:

1. التاريخ والوقت.
2. اسم الجزء المتأثر (تطبيق، لوحة إدارة، API، قاعدة بيانات، استضافة).
3. وصف واضح لما تغير وسبب التغيير.
4. الملفات أو الوحدات الرئيسة المتأثرة.
5. حالة النشر: محلي فقط / منشور / يحتاج متابعة.
6. الاختبارات التي أُجريت.
7. أثر الرجوع إن كان موجوداً، وأي ترحيل لقاعدة البيانات.

> لا تُكتب كلمات مرور أو مفاتيح أو بيانات حساسة في هذا السجل.

## 2026-09-05 — الدردشة الفورية عبر Pusher

- **الخصوصية:** الحدث لا يحمل نص الرسالة، بل معرّف المحادثة والرسالة فقط؛ المحتوى يُجلب دائماً من واجهة الرسائل المصرّح لها. قنوات Pusher الخاصة تتحقق من طرف المحادثة أو صلاحية الإدارة.
- **الملفات أو الوحدات:** ناشر Pusher خفيف لا يحتاج مكتبة Composer إضافية، تفويض خاص للمحادثة، وواجهات `ChatThread` و`Admin/Chat`.
- **النشر:** نُشر في `almunjaz-20260905-pusher-chat-r27`؛ مفاتيح Pusher تبقى في ملف بيئة خاص على الاستضافة ولا تدخل في الأرشيف.
- **التحقق:** نجح `npm run build`، والتحقق النحوي لـ PHP، و10 اختبارات للدردشة (242 assertion).
- **الرجوع:** جعل `PUSHER_CHAT_ENABLED=false` أو الرجوع للإصدار السابق؛ يبقى الاستعلام الدوري كبديل تلقائي.

## 2026-09-05 — إشعارات OneSignal

- **النوع:** التطبيق ولوحة الإدارة / الإشعارات.
- **التغيير:** ربط إشعارات النظام والطلبات المحفوظة بحساب OneSignal للمستخدم نفسه عبر معرّف خارجي ثابت؛ يبقى صندوق الإشعارات داخل التطبيق مصدر الحقيقة في حال كان الهاتف غير متصل أو الإذن مرفوضاً.
- **الويب:** إضافة SDK وعامل OneSignal ضمن نطاق مستقل كي لا يتعارض مع عامل الـPWA الحالي.
- **أندرويد:** إضافة SDK إلى تطبيق المندوب، ربط الحساب عند الدخول، فك الربط عند الخروج، وطلب إذن الإشعارات من النظام.
- **الأمان:** مفتاح OneSignal محفوظ في ملف بيئة محمي على الاستضافة ولا يدخل في الكود أو الأرشيف.
- **النشر:** نُشر الخادم والويب في `almunjaz-20260905-onesignal-r28`.
- **تصحيح الاستضافة:** نُسخت ملفات الواجهة فعلياً إلى نطاقي الويب بدلاً من الروابط الرمزية التي تمنعها الاستضافة بـ403. تم إيقاف تهيئة OneSignal للويب حتى يكتمل إعداد نطاق Web Push في لوحة OneSignal؛ لا يؤثر ذلك في تطبيق أندرويد الأصلي.
- **التحقق:** صفحة الدخول وعامل OneSignal الحي يعملان، و`flutter analyze` ناجح.
